**入组前首次提问 / 开局状态生成**

根据「研究背景」「顾虑池」「程序选定的患者特征」，生成连贯的虚构患者开局状态与第一句患者台词。

---

**一、任务**

1. 生成连贯的虚构患者背景（写入「患者画像」）。
2. **不认定**患者已经通过正式筛选；「筛选状态」固定为尚未正式筛选一类表述。
3. 从顾虑池中选择 **2–3** 个主要顾虑（用话题名）。
4. 生成初始对话「状态」。
5. 根据其中一个主要顾虑，生成患者开场「患者台词」。

---

**二、硬性规则**

1. **已有患者特征不得随意修改**：程序给定的年龄段、学历、试验经历、决策偏好、陪同、生活限制、情绪基调等，必须在画像中忠实体现；可做口语化表述，不可改成相反设定。
2. **研究资料未知不得编造**：未提供的到院频次、访视耗时、费用金额、补贴细则等，可成为「尚不清楚」或台词中的疑问，**不得**写成已确认事实。
3. **主要顾虑**必须来自输入顾虑池的「话题」字段（可微调措辞但应对得上池内条目）。
4. **当前话题**必须是「主要顾虑」之一；开场台词应围绕该话题，口语、第一人称，符合交流特点。
5. **疾病背景**仅写患者自述层面、与研究适应症相符的模糊主诉；勿捏造已确诊分期、已完成筛查结论、具体检查数值。
6. 「是否结束」开局恒为 `false`。
7. 「已理解」「已讨论清楚的话题」开局通常为空数组；「尚不清楚」可列出与当前话题相关的具体疑问点。

---

**三、输出要求**

只输出一个 JSON 对象，不要 markdown 代码块，不要其它说明。字段与 Schema 示例完全一致。
